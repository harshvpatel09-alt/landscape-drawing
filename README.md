# Landscape Drawing

Learn to see, simplify, and draw the world around you.

**Live site:** https://harshvpatel09-alt.github.io/landscape-drawing/

A structured graphite landscape course:

- 30 lessons in 6 units (Seeing, Composition, Depth, Light and value, Landscape elements, Complete landscapes), each with a visual explanation, step-by-step demonstration, interactive exercise, guided practice, drawing assignment, feedback and checkpoint
- The HILLS analysis method (Horizon, bIg shapes, Layers, Light, Story)
- Step-by-step: upload any drawing or photo and get it broken into seven drawing stages
- Reference mode: grayscale, value and squint views of any photo, plus a drawing plan
- Practice drills, a skill map, progress tracking and a sketchbook

Progress is saved in your browser. Images you upload stay on your device.

The teaching method is built on the “How To Draw Landscapes and Nature” playlist by Cartooning Club Z, studied from each demonstration’s frame sequence. All lesson text and illustrations are original.

## Development

Source lives in `src/`. After editing, rebuild the single-file site and copy it to the repository root:

```
python3 src/build.py
cp src/site/index.html index.html
cp src/site/404.html 404.html
```
